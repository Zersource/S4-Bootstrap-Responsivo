# GameZone - Bootstrap 5, Diseño Responsivo y DOM con JavaScript

Actividad formativa individual de la asignatura **Desarrollo Frontend I (PFY2201)** — DuocUC.

## Descripción

Proyecto GameZone (tienda ficticia de videojuegos), desarrollado semana a semana sobre el mismo sitio.

**Semana 4 — Bootstrap y diseño responsivo:**
- **Navbar** responsiva con colapso en dispositivos móviles
- **Carousel** con transición automática cada 3 segundos
- **Grid System** (sistema de cuadrículas) para estructurar el contenido principal
- **Cards** para mostrar el catálogo de productos

**Semana 5 — Manipulación del DOM con JavaScript:**
- Validación y respuesta al evento `submit` del formulario de contacto
- Expandir/colapsar detalle de cada card al hacer click (`createElement`, `appendChild`)
- Resalte visual de las cards con `mouseover`/`mouseout`
- Carga de juegos adicionales vía **Fetch API** (`juegos.json`), con manejo de errores

## Tecnologías

- HTML5 semántico
- Bootstrap 5.3.3 (vía CDN)
- CSS3 (ajustes puntuales)
- JavaScript (DOM, eventos, Fetch API)
