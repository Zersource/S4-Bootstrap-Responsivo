# GameZone - Semana 4: Bootstrap 5 y Diseño Responsivo

Actividad formativa individual de la asignatura **Desarrollo Frontend I (PFY2201)** — DuocUC.

## Descripción

Implementación de una página web responsiva utilizando **Bootstrap 5.3**, aplicada al proyecto GameZone (tienda ficticia de videojuegos). La actividad integra los siguientes componentes de Bootstrap:

- **Navbar** responsiva con colapso en dispositivos móviles
- **Carousel** con transición automática cada 3 segundos
- **Grid System** (sistema de cuadrículas) para estructurar el contenido principal
- **Cards** para mostrar el catálogo de productos

## Tecnologías

- HTML5 semántico
- Bootstrap 5.3.3 (vía CDN)
- CSS3 (ajustes puntuales)

## Estructura del repositorio

├── index.html          # Página principal (rama gh-pages y main)
├── img/                # Imágenes locales (banners y cards)
